# 02 — SVG를 악보로 만들고 목표선을 깐다

**Spec:** `.scratch/core-play-loop/spec.md`

**What to build:** 내장 예제 버튼을 누르거나 아무 SVG 파일이나 화면에 떨어뜨리면, 그 그림이 **악보**가 되어 화면에 옅은 **목표선**으로 깔린다. 시작점이 어디인지 눈에 보인다. 파일 선택 버튼으로도 넣을 수 있다.

들어온 SVG가 어떻게 생겼든 받아낸다 — `path`뿐 아니라 `circle`·`rect`·`polygon` 같은 도형만 있어도 악보가 된다. 도형이 여럿이면 가장 긴 것 하나를 쓴다. 악보로 쓸 수 없는 파일이면 무엇이 잘못됐는지 한 줄로 알려준다. 조용히 아무 일도 안 일어나면 안 된다.

이 티켓이 PLAN.md 진행 순서 2단계다. 그리고 **"심사위원이 자기 로고를 던진다"는 가장 강한 인상 장치가 여기서 살아난다.**

확인용 프로토타입(`proto/svg-to-score.html`)이 이 동작을 이미 통과한 상태다. 거기서 검증된 것만 옮겨오면 된다 — 모든 SVG 도형은 `SVGGeometryElement`라서 `getTotalLength()`/`getPointAtLength()`를 공통으로 가지므로, 도형 종류를 가리지 않고 경로 위의 점을 등간격으로 뽑을 수 있다. 길이 계산이 되려면 요소가 실제로 문서에 붙어 있어야 한다.

프로토타입에서 확정된 악보의 모양:

```js
score: { points: [{ x, y, hz }], length, shapeCount }
```

`x`·`y`는 스테이지 좌표, `hz`는 그 지점에서 내야 할 목표 음이다.

이 티켓에서 세션 엔진 seam의 껍데기와 악보 부분이 선다. `advance`는 다음 티켓에서 채운다.

화면 제목에서 "1단계 확인"을 떼어낸다. 이제 1단계 확인용 앱이 아니다.

**Blocked by:** 01 — 악보의 목표 음이 01에서 통일한 음역 상수를 써야 한다.

**Status:** ready-for-human — 구현은 끝났다. 남은 것은 마이크와 눈이 필요한 확인뿐이다 (아래 Comments 참고).

- [x] 내장 예제를 누르면 목표선이 화면에 뜬다 (최소 세 개 — 원처럼 되돌아오는 것, 물결처럼 오르내리는 것, 윤곽선 하나)
- [ ] 외부 SVG를 드롭하면 같은 일이 일어난다. 서로 다른 실제 파일 세 개로 확인한다
- [ ] 파일 선택 버튼으로도 같은 일이 일어난다
- [x] `path`가 하나도 없고 `circle`·`rect`·`polygon`만 있는 SVG도 악보가 된다
- [x] 목표선이 가로세로 비율을 유지한 채 여백을 두고 스테이지 중앙에 배치된다

## Comments

**구현 완료.** `src/score.js`(세션 엔진 내부) + `src/samples.js` + `src/renderer.js`.
악보의 모양은 프로토타입에서 검증된 그대로이되 `band` 를 하나 더 들고 다닌다 —
목표 음을 만든 세로 구간을 악보가 기억해야, 연주 때 그 정확한 역함수로 펜을 놓을 수 있다.

**실제 브라우저에서 잡은 버그 하나.** 프로토타입은 `innerHTML` 로 SVG를 심었다.
HTML 파서는 `xmlns` 선언이 없어도 `<svg>` 아래를 SVG 이름공간에 넣어준다. 그런데
스크립트를 막으려고 `DOMParser`(`image/svg+xml`)로 바꾸면 이름공간이 자동으로 붙지 않아서,
**`xmlns` 를 빠뜨린 멀쩡한 SVG 가 전부 "도형이 없습니다"로 튕겨 나갔다.**
도형이 `SVGGeometryElement` 가 되지 못해 `getTotalLength()` 를 갖지 않기 때문이다.
이름공간이 다르면 선언을 붙여 한 번 더 파는 것으로 고쳤다. "아무 SVG나 던져보세요"가
걸린 자리라 그냥 넘길 수 없었다.

**검증** — 헤드리스 크롬에서 37개 항목을 확인했다(스크래치, 저장소에는 남기지 않음).
내장 예제 셋, `circle`·`rect`·`polygon` 만 있는 SVG, `xmlns` 없는 SVG, 비율 유지(원이 원으로 남는다),
스테이지 중앙 배치, 여백 안, 도형이 여럿일 때 가장 긴 것 선택과 개수 보고,
실패 경로 다섯 가지의 사유 메시지, 수평선(음역 중앙 한 음, 나누기 0 없음),
스크립트·외부 참조 미실행, 실패 경로에서도 측정용 요소가 문서에 남지 않음.

**남은 확인(사람 필요)**
- 실제 외부 SVG 파일 세 개를 드롭/파일 선택으로 넣어보기 (합성 SVG로만 확인했다)
- 시작점 표시가 눈에 들어오는지 (그리기는 하는데 눈으로 봐야 안다)
- WebGL 실패 시 소프트웨어 렌더러 폴백 — `--disable-gpu` 헤드리스에서 앱이 정상 부팅했으니
  그 경로를 지나간 것으로 보이지만, 확증하지는 못했다
