# 05 — 완주 · 결과 화면 · 화면 상태 전이

**Spec:** `.scratch/core-play-loop/spec.md`

**What to build:** 경로 끝에 닿으면 연주가 끝나고 **결과 화면**이 뜬다. 목표선과 내가 그린 궤적이 겹쳐 보인다 — 얼마나 비슷한지가 이 게임의 결말이다. 곧바로 다시 할 수 있고, 같은 악보로 한 번 더 할지 새 SVG를 넣을지 고를 수 있다.

지금까지 티켓들이 각자 만든 조각을 하나의 흐름으로 묶는 티켓이기도 하다. 앱이 네 상태를 오간다.

- **대기** — 악보 없음. 예제 버튼·파일 입력·드롭 영역이 보인다
- **준비** — 악보 있음, 연주 전. 목표선이 깔려 있고 가이드 음을 들을 수 있다
- **연주** — 펜이 진행 중
- **결과** — 목표선과 궤적이 겹쳐 보인다

새 SVG 드롭은 어느 상태에서든 받고, 받으면 준비 상태로 돌아간다.

**가이드 음과 연주는 배타적으로 묶는다.** 스피커로 나간 가이드 음이 마이크로 되돌아오면 사용자가 침묵해도 펜이 진행한다. 헤드폰을 전제로 한 동시 재생 모드는 이 스펙 밖이다.

끝나는 순간이 있어야 해냈다는 느낌이 든다. 지금까지는 시작도 끝도 없이 선이 흐르기만 했다. 발표 중에는 결과 화면이 몇 초 만에 나타나고 다음 시연으로 바로 넘어갈 수 있어야 한다 — 흐름이 끊기면 안 된다.

**Blocked by:** 03, 04 — 궤적과 완주 신호(03), 배타적으로 묶을 가이드 재생(04)이 모두 있어야 한다.

**Status:** ready-for-human — 구현은 끝났다. 남은 것은 마이크와 눈이 필요한 확인뿐이다 (아래 Comments 참고).

- [ ] 진행도가 끝에 닿으면 연주가 끝나고 결과 화면으로 넘어간다
- [x] 완주 후 추가로 소리를 내도 궤적과 진행도가 더 변하지 않는다
- [ ] 결과 화면에서 목표선과 궤적이 겹쳐 보이고, 둘이 구분된다
- [ ] 그린 그림의 앞부분부터 끝까지 전부 남아 있다
- [ ] 결과 화면에서 같은 악보로 다시 하기가 클릭 한 번에 된다
- [ ] 결과 화면에서 새 SVG로 넘어갈 수 있다

- [ ] 네 상태(대기·준비·연주·결과)마다 보이는 것과 누를 수 있는 것이 그 상태에 맞다

- [ ] 처음 열었을 때 무엇을 해야 하는지 설명 없이 알 수 있다
- [ ] 마이크 권한을 언제 왜 요구하는지 알 수 있고, 거절했거나 장치가 없으면 무엇이 문제인지 알려준다

## Comments

**구현 완료.** 상태는 `document.body[data-state]` 하나로 관리하고, 무엇이 보이는지는
CSS 가 정한다. 진입점에는 상태 전이만 남아 있다.

`대기 → 준비 → 연주 → 결과` 를 오가고, 새 SVG 드롭은 어느 상태에서든 받는다.
드롭이 실패하면 **이전 악보를 그대로 둔다** — 새 악보가 성공했을 때만 갈아탄다.
연주 중 드롭해도 죽지 않고 준비 상태로 간다.

결과 화면의 `다시 하기`는 준비 상태를 거치지 않고 곧바로 연주로 들어간다. 클릭 한 번이다.
결과에서 가이드 음을 누르면 준비 상태로 돌아가며 재생한다 — 듣고 다시 하려는 흐름이다.

계기판과 버튼은 스테이지 **아래**에 둔다. 목표선과 궤적을 가리지 않아야 해서다.

**검증** — 헤드리스에서 `대기 → 준비` 전이와 상태별 노출을 확인했다.
대기에서는 예제 버튼 3개만 보이고 `시작`과 계기판이 숨겨져 있으며, 예제를 누르면
준비로 넘어가 가이드·시작·계기판·마이크 안내가 한꺼번에 나타난다. 다른 예제로 갈아타도
준비 상태를 유지한다. 완주 후 상태가 더 변하지 않는 것은 세션 쪽에서 수치로 확인했다.

**남은 확인(사람 필요)**
- 결과 화면에서 목표선과 궤적이 겹쳐 보이고 둘이 구분되는지
- 다시 하기 / 그만두기 / 새 SVG 갈래 (마이크가 있어야 연주까지 간다)
- 마이크 권한을 거절했을 때의 안내 (문구는 넣어뒀지만 실제로 거절해봐야 한다)
- **전체 흐름(예제 → 가이드 음 → 연주 → 결과 → 다시)이 끊김 없이 한 번에 도는지**
