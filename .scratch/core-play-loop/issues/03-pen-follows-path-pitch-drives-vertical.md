# 03 — 펜이 목표선을 따라 진행하고, 세로는 음정이 정한다

**Spec:** `.scratch/core-play-loop/spec.md`

**What to build:** **여기서 게임이 성립한다.** 프로젝트 전체에서 가장 중요한 티켓이다.

시작하면 펜이 경로의 시작점에 선다. 소리를 내면 펜이 경로를 따라 앞으로 나아간다. 펜의 **가로 위치는 악보가 정한 대로** 흐르고, **세로 위치는 사용자가 내는 음의 높이만이** 결정한다. 악보의 세로 좌표는 펜의 세로에 전혀 영향을 주지 않는다 — 목표선은 눈으로 보라고 있는 것이지 펜을 끌고 가지 않는다.

정확한 음을 내면 궤적이 목표선 위에 겹치고, 틀린 음을 내면 그 지점에서 위아래로 벗어난다. 지나온 자리에는 궤적이 남는다. 이미 지나온 목표선과 아직 남은 목표선이 구분된다.

**소리를 멈추면 펜이 그 자리에 선다.** 진행도는 음정이 잡히는 프레임에만 증가한다. 다시 소리를 내면 멈췄던 자리에서 이어진다. 결과적으로 숨이 곧 시간이 된다 — 숨을 고르는 동안 그림이 망가지지 않고, 그래서 처음 잡는 사람도 완주할 수 있다.

이 티켓이 PLAN.md 진행 순서 3단계다.

기존 진입점의 "가로는 시간, 오른쪽 끝에서 되감기" 동작은 이 티켓으로 **대체되어 사라진다.** 스윕 시간 상수와 되감기 로직을 남기지 않는다. 부분 수정보다 세션 엔진을 세우고 진입점을 거기에 맞춰 다시 배선하는 편이 빠르다.

02에서 껍데기만 선 세션 엔진 seam의 `advance`를 채운다. 이 경계 안에는 렌더링도 마이크도 들어오지 않는다 — 나중에 테스트를 붙일 때 손댈 곳을 한 군데로 유지하기 위한 제약이다.

```js
advance({ hz, dt }) → {   // hz 가 null 이면 펜이 멈춘다
  pen: { x, y },
  progress,               // 0~1
  trail: [{ x, y }],
  targetHz,               // 지금 내야 할 음
  errorCents,             // 목표 대비 오차 (센트)
  done,
}
```

진행 속도는 경로의 실제 길이가 아니라 **목표 완주 시간** 상수에서 나온다. 긴 경로든 짧은 경로든 체감 길이가 같아진다. 30초짜리 곡이 되면 아무도 끝까지 하지 않는다.

궤적의 점 상한에 닿았을 때 **오래된 점을 버리면 안 된다.** 그린 그림의 앞부분이 사라져 다음 티켓의 결과 화면이 성립하지 않는다. 점 사이를 솎아내는 방식으로 줄인다.

**Blocked by:** 02 — 따라갈 악보와 목표선이 있어야 한다.

**Status:** ready-for-human — 구현은 끝났다. 남은 것은 마이크와 눈이 필요한 확인뿐이다 (아래 Comments 참고).

## Comments

**구현 완료.** `src/session.js` 가 seam 이다. 안에 ThorVG 도 마이크도 들어오지 않는다.
스윕 시간 상수와 되감기 로직은 진입점에서 사라졌다.

악보를 만드는 일과 연주를 진행하는 일을 갈라 `createSessionFromScore(score)` 를 따로 냈다.
`createSession(svgText)` 은 그 위의 껍데기다. 악보 추출은 `getTotalLength()` 가 필요해
실제 브라우저를 요구하지만, **진행 규칙만은 브라우저 없이 확인할 수 있게** 하려는 것이다.
스펙이 말한 "seam 은 테스트를 염두에 두고 만든다"를 지키는 쪽으로 판단했다.

**검증** — 18개 항목을 수치로 확인했다(스크래치, 저장소에는 남기지 않음).
- 목표 음을 그대로 먹이면 궤적이 목표선에서 최대 4.5px 안에 붙는다. 남는 오차는 세로
  스무딩이 목표를 뒤따라오는 지연분이고 선 굵기(4px) 안쪽이다. **목표가 멈춰 있는 악보에서는
  1e-9px 안으로 정확히 수렴하고 오차가 0센트다** — 매핑이 정확한 역함수라는 증거다.
- 한 옥타브 위를 먹이면 프레임의 95% 이상에서 목표선 위로 벗어난다.
- 무음을 계속 먹이면 진행도·궤적·펜 위치가 전부 그대로고 오차 표시도 비워진다.
- 멈췄다 다시 내면 멈춘 진행도에서 이어진다.
- 완주 시간이 목표 완주 시간(20초)과 0.1초 안에서 일치하고, 점 50개짜리와 4000개짜리
  악보의 완주 시간이 같다.
- 완주 후에는 무엇을 먹여도 진행도·궤적이 변하지 않는다.
- 궤적 상한(2000점)에 닿아도 **첫 점이 그대로 남고** 순서가 유지된다.

**남은 확인(사람 필요)**

- 실제 목소리로 스무딩 세기가 맞는지
- 연주 도중 "처음부터" 버튼
- **즉시성** — 이건 사람이 소리를 내봐야만 알 수 있고, 무너지면 다른 게 다 돼도 실패다
